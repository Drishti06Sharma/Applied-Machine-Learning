Experiment 7: Iris Flower Classification¶

Aim¶

To develop a supervised machine learning model using Python and Scikit-learn to classify Iris flowers into Setosa, Versicolor, and Virginica based on sepal and petal measurements.

Learning Objectives¶

  • Understand a labelled classification dataset.
  • Explore and visualize the dataset.
  • Split the data into training and testing sets.
  • Train Logistic Regression, K-Nearest Neighbours, and Decision Tree classifiers.
  • Evaluate models using accuracy, precision, recall, F1-score, and a confusion matrix.
  • Compare model performance and predict the species of a new flower.

Software Requirements¶

Python, Jupyter Notebook, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.

Dataset Description¶

The Iris dataset contains 150 flower samples, four numerical input features, and three target classes. Each class contains 50 samples.

Feature Description Unit
Sepal length Length of the sepal cm
Sepal width Width of the sepal cm
Petal length Length of the petal cm
Petal width Width of the petal cm
Target Iris flower species Setosa, Versicolor, Virginica

The input features are the sepal and petal measurements, while the target variable represents the species.

The dataset is divided into 80% training data and 20% testing data. The training set is used to train the model, while the testing set evaluates its performance on unseen samples.

The stratify=y parameter preserves the class proportions in both sets. The random_state=42 parameter makes the split reproducible.

Model 1: Logistic Regression¶

Logistic Regression is a supervised classification algorithm that estimates the probability of an input belonging to a particular class. Although its name contains the word regression, it is used for classification tasks.

StandardScaler is applied through a Pipeline to standardize the input features. The scaler is fitted only on the training data to prevent data leakage.

Confusion Matrix Interpretation¶

A confusion matrix compares actual classes with predicted classes.

  • Rows represent actual classes.
  • Columns represent predicted classes.
  • Diagonal elements represent correct predictions.
  • Off-diagonal elements represent incorrect predictions.

A good classifier has high values along the main diagonal and few values outside it.

Comparison of Classification Algorithms¶

Three supervised learning algorithms are evaluated using the same training and testing split.

  1. Logistic Regression: A linear classification algorithm.
  2. K-Nearest Neighbours (KNN): Classifies a sample based on the classes of its nearest neighbours.
  3. Decision Tree: Classifies samples using a sequence of feature-based decision rules.

Weighted precision, recall, and F1-score are used to compare model performance.

In [9]:
knn_model = Pipeline([
    ("scaler", StandardScaler()),
    ("classifier", KNeighborsClassifier(n_neighbors=5))
])

dt_model = DecisionTreeClassifier(random_state=42)

models = {
    "Logistic Regression": lr_model,
    "KNN": knn_model,
    "Decision Tree": dt_model
}

results = []
predictions = {}

for name, model in models.items():
    model.fit(X_train, y_train)
    pred = model.predict(X_test)
    predictions[name] = pred

    results.append({
        "Model": name,
        "Accuracy": accuracy_score(y_test, pred),
        "Precision": precision_score(
            y_test, pred, average="weighted", zero_division=0
        ),
        "Recall": recall_score(
            y_test, pred, average="weighted", zero_division=0
        ),
        "F1-score": f1_score(
            y_test, pred, average="weighted", zero_division=0
        )
    })

comparison = pd.DataFrame(results)
print(comparison.round(4).to_string(index=False))

best_model = comparison.loc[comparison["Accuracy"].idxmax(), "Model"]
print("\nBest model based on test accuracy:", best_model)

Effect of StandardScaler¶

StandardScaler transforms each feature to have approximately zero mean and unit variance based on the training data.

KNN relies on distances between samples, so scaling is particularly important. Logistic Regression may also benefit from scaling. Decision Trees generally do not require feature scaling because their splits depend on feature thresholds.

Five-Fold Cross-Validation¶

Cross-validation divides the dataset into five folds. In each iteration, four folds are used for training and one fold is used for validation. Each fold is used once for validation.

The mean accuracy provides a more stable estimate of model performance than a single train-test split.

In [13]:
cv_model = Pipeline([
    ("scaler", StandardScaler()),
    ("classifier", LogisticRegression(max_iter=200))
])

cv_scores = cross_val_score(
    cv_model, X, y,
    cv=5,
    scoring="accuracy"
)

print("Accuracy for each fold:", cv_scores)
print("Mean accuracy:", cv_scores.mean())
print("Standard deviation:", cv_scores.std())
