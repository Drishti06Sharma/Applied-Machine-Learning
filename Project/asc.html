Objective¶

The objective of this project is to predict the total number of bikes rented per hour using machine learning regression algorithms. The model considers factors such as season, temperature, humidity, weather conditions, working day, and hour of the day.

Problem Statement¶

Accurate bike rental demand prediction can help bike-sharing services manage bicycle availability and improve resource allocation.

6. Data Preprocessing¶

Data preprocessing is an important step in machine learning that prepares the dataset for model training.

In this project, the target variable is cnt, which represents the total number of bikes rented.

We remove unnecessary columns such as:

  • instant: Record index.
  • dteday: Date information.
  • casual: Number of casual users.
  • registered: Number of registered users.

The columns casual and registered are removed because their sum directly represents the target variable cnt. Keeping them would cause target leakage.

The remaining relevant features are used as input variables for predicting bike rental demand.

# Remove unnecessary columns

8. Model Training¶

In this section, we train four different machine learning regression algorithms to predict hourly bike rental demand.

The algorithms used are:

  1. Linear Regression
  2. Decision Tree Regressor
  3. Random Forest Regressor
  4. Gradient Boosting Regressor

Each model learns patterns from the training dataset and predicts the number of bikes rented based on the input features.

In [11]:
# Define regression models

models = {
    "Linear Regression": LinearRegression(),

    "Decision Tree": DecisionTreeRegressor(
        random_state=42,
        max_depth=15
    ),

    "Random Forest": RandomForestRegressor(
        n_estimators=100,
        random_state=42,
        n_jobs=-1
    ),

    "Gradient Boosting": GradientBoostingRegressor(
        n_estimators=100,
        random_state=42
    )
}

results = []
trained_models = {}

# Train all models
for name, model in models.items():

    model.fit(X_train, y_train)

    y_pred = model.predict(X_test)

    mae = mean_absolute_error(y_test, y_pred)
    mse = mean_squared_error(y_test, y_pred)
    rmse = np.sqrt(mse)
    r2 = r2_score(y_test, y_pred)

    results.append({
        "Model": name,
        "MAE": mae,
        "MSE": mse,
        "RMSE": rmse,
        "R2 Score": r2
    })

    trained_models[name] = model

    print(name, "trained successfully!")

print("\nAll models trained successfully!")

9. Model Evaluation¶

After training the four regression models, we evaluate their performance using the following evaluation metrics:

  1. Mean Absolute Error (MAE): Measures the average absolute difference between actual and predicted values.
  2. Mean Squared Error (MSE): Measures the average squared difference between actual and predicted values.
  3. Root Mean Squared Error (RMSE): Represents the square root of MSE and indicates prediction error in the original unit.
  4. R² Score: Measures how well the model explains the variation in bike rental demand.

Lower MAE, MSE, and RMSE values indicate better performance, while a higher R² score indicates a better model.
